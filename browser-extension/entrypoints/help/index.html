Help & privacy

From a model page to your library

You need a running PrintStash server and an account on it to use this extension.

  1. In PrintStash, open Settings → Imports and create a browser pairing code.
  2. Open the extension. Enter your Vault URL and the code, then choose Pair browser. Codes expire after five minutes.
  3. Open a supported model page and choose Send to Pending Imports. Select files when prompted.
  4. Keep the popup open during the transfer. Open Pending Imports in PrintStash to review the files and finish importing.

Local addresses such as localhost:8000 and 192.168.1.20:8000 work without a scheme. Use HTTPS for a remote server.

Supported sources

  • MakerWorld: individual model pages. Sign in to MakerWorld in the same browser. Collections are not supported.
  • Printables: model pages and collections. Available files depend on the page and your source-site access.
  • Thingiverse: individual model pages, with file selection and manual attachment when automatic download is unavailable.
  • Direct links: ZIP, 3MF, STL, OBJ, STEP/STP and G-code files, where your server can safely download them.

Source sites can require sign-in or browser checks. The extension does not bypass access restrictions. If a transfer stops, check Pending Imports before retrying.

Privacy policy

This policy covers the PrintStash browser extension. The extension sends the models you choose to the PrintStash server you configure. It has no advertising, analytics or telemetry service.

Data used by the extension

When you open the popup, it reads the active page URL and title to identify a supported source and checks your configured server. During a capture you initiate, it reads supported page metadata and downloads selected files. This can include the model title, description, creator, license and source URL.

The extension stores the Vault URL and a browser device credential locally in your browser. A pairing code is exchanged once and is not saved. If you choose the legacy setup, your username and named API key are stored locally instead. Temporary access tokens remain in memory.

Where data goes

Selected files and allowlisted source metadata go to your configured PrintStash server for review and import. Credentials are sent to that server for authentication. Requests to model providers and their file hosts obtain the content you select; those services receive ordinary network information such as your IP address.

Provider requests may use the sign-in session already present on the source page. Source-site cookies and session credentials are never copied into the import or sent to PrintStash. Raw page HTML and signed download URLs are not retained as source metadata.

The extension does not sell data, use it for advertising, or transfer it to an analytics service. Data is used only to connect your browser and import the content you request. Your PrintStash administrator controls the server's storage, access and backups; source sites have their own privacy policies.

Permissions

Active tab and scripting let the extension identify the page you open it on and run bundled extraction code when you capture. It does not monitor your browsing in the background.

Storage remembers the connection locally. Host access connects to a local PrintStash server or, with your approval, your chosen server and the provider hosts needed for a transfer. Optional HTTP/HTTPS access allows self-hosted servers at different addresses; it does not grant all websites at installation.

Your controls

Use Edit → Disconnect in the popup to remove the saved connection credentials. Revoke the paired browser in PrintStash Settings → Imports to invalidate its credential on the server. Remove additional site permissions through your browser's extension settings, or uninstall the extension.

Disconnecting does not delete existing imports. Dismiss a pending item or delete imported content in PrintStash to manage server data; retention and backups are controlled by that server's administrator.

Contact

For extension questions, use the PrintStash issue tracker. Do not post pairing codes, credentials or private model files. For server-held data, contact your PrintStash administrator.
