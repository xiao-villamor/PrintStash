# Browser Extension Compatibility

Start with the [browser capture guide](https://www.printstash.org/en/docs/guides/browser-capture/)
for pairing and supported import workflows. If you build from source, use the
[extension README](https://github.com/xiao-villamor/PrintStash/blob/main/browser-extension/README.md)
from the same release tag as your server for browser-specific instructions.

Use the popup's **Version** value to identify the installed build when
troubleshooting. The server and extension have independent version numbers.
Create a browser pairing code from **Settings → Imports**, then review
captured files in **Pending Imports**.
