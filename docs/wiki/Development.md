# Development

Use [CONTRIBUTING.md](https://github.com/xiao-villamor/PrintStash/blob/main/CONTRIBUTING.md#development-setup)
for local backend and frontend setup. For work on an older release, read that
file and the dependency manifests from the tag you checked out.

Run Vite to see frontend source edits. The default Docker Compose deployment
on port 3000 serves the app from the published image.

Coding assistants and contributors should start with
[AGENTS.md](https://github.com/xiao-villamor/PrintStash/blob/main/AGENTS.md) for
repository rules, the PrintStash skill, and the applicable verification
commands. See the [backend guide](https://github.com/xiao-villamor/PrintStash/blob/main/backend/README.md)
for migrations and layout, and the [browser extension README](https://github.com/xiao-villamor/PrintStash/blob/main/browser-extension/README.md)
for extension builds and tests.
