# User Guide

Start with [first run](https://www.printstash.org/en/docs/getting-started/first-run/)
to create an account, select storage, and upload a file or connect a library
source. Follow the [everyday library workflow](https://www.printstash.org/en/docs/guides/user-guide/)
to organize Models, attach G-code Revisions, and record print outcomes.

- [Folders and NAS](https://www.printstash.org/en/docs/guides/shared-volumes/)
- [Browser capture](Browser-extension-compatibility)
- [Printer setup](https://www.printstash.org/en/docs/guides/printers/) and
  [provider capabilities](https://github.com/xiao-villamor/PrintStash/blob/main/docs/provider-support.md)
- [Backups and restore](https://www.printstash.org/en/docs/guides/backup-and-restore/)
- [Known limitations](https://github.com/xiao-villamor/PrintStash/blob/main/docs/known-limitations.md)
