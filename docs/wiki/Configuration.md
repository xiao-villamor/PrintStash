# Configuration

The default Compose deployment uses SQLite and a single persistent mount at
`/data`. See [deployment and optional settings](https://github.com/xiao-villamor/PrintStash/blob/main/docs/deployment.md)
for supported environment variables, host folders, PostgreSQL, and worker
topologies. Use the Compose and example files from the release you are running
when checking a specific setting.

- [First-run administrator setup](https://github.com/xiao-villamor/PrintStash/blob/main/docs/first-run.md)
- [Storage provider setup and safety tiers](https://github.com/xiao-villamor/PrintStash/blob/main/docs/storage-providers.md)
- [Disaster recovery](https://github.com/xiao-villamor/PrintStash/blob/main/docs/disaster-recovery.md)
