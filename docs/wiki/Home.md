# PrintStash Wiki

PrintStash is a self-hosted library for 3D Models, G-code Revisions, and print
history. Start with the [PrintStash documentation](https://www.printstash.org/en/docs/)
for user guides or the [repository documentation index](https://github.com/xiao-villamor/PrintStash/blob/main/docs/README.md)
for deployment, storage, and contributor references.

## Start here

- [Installation](Installation) covers published images, first run, and upgrades.
- [User guide](User-guide) covers library, capture, printer, and backup workflows.
- [Configuration](Configuration) covers deployment settings and data paths.
- [Development](Development) points contributors to the setup and verification
  instructions for their checkout.
- [API](API) and [Architecture](Architecture) point to the integration and
  implementation references.

[GitHub Releases](https://github.com/xiao-villamor/PrintStash/releases/latest)
lists the latest published release and its changes. For an existing
installation, check the [upgrade guide](https://github.com/xiao-villamor/PrintStash/blob/main/UPGRADE.md)
before changing image tags.
