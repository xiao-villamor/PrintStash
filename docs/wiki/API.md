# API

Use the [API reference](https://www.printstash.org/en/docs/reference/api/) for
authentication, permissions, and common integration workflows. Check the
OpenAPI schema for your installed version when you need the exact endpoint or
request shape.

The default Compose deployment serves the API under `/api/v1` on the same
origin as the web app. A local development backend serves Swagger UI at
<http://localhost:8000/docs>. See [Development](Development) for setup.
