# Native worker startup qualification

[ADR-0016](../adr/0016-native-worker-startup.md) records the measured decision. The external child import boundary refuses only parent application observations and SQLAlchemy; production admission, bootstrap, source parsing, rendering, reply framing and cleanup remain real. Four initial metrics-boundary cases and four later SQLAlchemy-boundary cases failed before their respective fixes.

Actual focused runs: 86 cases passed in 14.27 seconds (configuration and parent observations plus real fresh-child contracts); final helper, dependency-boundary, real Benchy, bootstrap and visual containment selection passed 30 cases in 21.57 seconds. Ruff/format, scoped Pyright and the real application dependency audit passed. The affected-test hygiene selection passed 47 cases (4,659 deselected) in 4.52 seconds. An earlier whole-file hygiene attempt exceeded its declared 60-second deadline and was interrupted without a reported assertion failure; it is not counted as passing. The local full/coverage/scale lanes were not repeated; normal PR CI is the exhaustive merge gate and Deep remains deferred until the implementation set is complete.

## Measurement scope

The three sequential arms each contain 30 fresh workers per input; the alternating confirmation adds 10 per arm/input. All 220 completed with matching source/output identities. Thirty separate admitted stdlib controls characterize launch and retirement alone. The [public sample table](../adr/0016-startup-pilot/samples.csv) retains first samples and all outcomes. Medians and residuals are scoped measurements, not cold-process Job percentiles; no source, parser state or numerical context is reused across Artifacts.
