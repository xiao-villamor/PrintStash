# Native resource admission acceptance

This change coordinates local API/worker processes sharing one data root. It
separates CPU/RAM credits from prepared-source bytes and active source I/O.
Checks below concern resource ownership, not tenant isolation or a cloud queue.
All paths are relative to `backend/tests/`.

The existing [mesh containment](mesh-containment.md) and
[mesh cancellation](mesh-cancellation.md) matrices retain their worker-process
contracts. Focused mixed-source execution, resource recovery and real PID
namespace qualification pass on Linux x86-64 / Python 3.14.8. Extended soak and
coverage remain separate release-gate checks; Deep CI has not been dispatched.
