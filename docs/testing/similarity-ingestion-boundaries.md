# Similarity ingestion boundaries

Optional fingerprint publication must preserve committed source authority, respect the current execution fence, and create only eligible durable analysis intent. Transactional continuations share the derivative caller’s write transaction.

Tests use real SQLite, factory entities, extracted tetrahedron descriptors, fingerprint leases and run creation. No persistence or analyzed behavior is mocked. The caller rollback scenarios start a physical write before publication; they do not establish atomicity for a read-only SQLite implicit transaction. Coverage floors remain unchanged and require the final GitHub Deep CI measurement.
