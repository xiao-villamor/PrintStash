# Fingerprint publication boundary contracts

Fingerprint retention in `docs/similar-models.md` reuses complete results and retries incomplete work under the current source authority. Precomputed ingestion must preserve the surrounding transaction and lease: stale inputs cannot create analysis, an active owner defers duplicate work, and invalid metadata must roll back the whole publication. These tests use real SQLite factory rows and descriptors extracted from the geometry factory.
