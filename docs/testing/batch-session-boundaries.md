# Batch session execution boundary contracts

The durable ingestion contract in docs/architecture/background-work.md requires immutable source snapshots, separate receipt outcomes, coherent discovery totals and exactly one terminal result per execution. These tests use real SQLite, stored Jobs and execution fences. Only the caller-provided artifact committer is controlled; batch storage and Job context are real.
