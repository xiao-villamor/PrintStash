# STL publication boundary contracts

The viewer contract in `docs/derivatives.md` requires a verified regular-file descriptor retained through publication, cooperative cancellation and source identity checks before READY. Original STL bytes must retain their byte semantics. These tests exercise real filesystem objects and the actual preparation/reader path; a filesystem permission failure is injected only at the source-open boundary.
