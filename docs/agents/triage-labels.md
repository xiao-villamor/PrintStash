# Triage labels

PrintStash uses the same strings as the upstream skills.

| Role | GitHub label | When it applies |
| --- | --- | --- |
| Needs triage | `needs-triage` | A maintainer needs to assess the request. |
| Needs information | `needs-info` | Reproduction details or a decision are missing. |
| Ready for an agent | `ready-for-agent` | The work has a scoped outcome and observable acceptance criteria. |
| Needs a human | `ready-for-human` | The next step requires a maintainer or user. |
| Declined | `wontfix` | A maintainer has declined the request. |

Use the existing classification labels such as `bug`, `enhancement`, and
`documentation` separately from readiness. Preserve labels unrelated to the
transition.
