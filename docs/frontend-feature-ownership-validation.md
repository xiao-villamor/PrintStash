## Owned flow inventory

- Documents: `components/document-browser.tsx` lists the active collection, creates draft routes, uploads local files and confirms trashing; `pages/document-detail.tsx` reads one document, edits markdown and fetches protected binary previews. Typed endpoints: `lib/api/documents.ts`.
- Inbox: `pages/inbox.tsx` groups queue/completed imports and confirms dismiss/batch cleanup; `pages/inbox-detail.tsx` reviews destination/tags/files, submits imports and retries. `components/bottom-nav-bar.tsx` and `components/sidebar-nav.tsx` count pending imports. Typed endpoints: `lib/api/inbox.ts`.
- Baseline ownership: Documents list/detail copy remote results in effects; list converts read failure to empty success. Inbox page/detail own separate completion pollers, plus a mobile badge interval and a desktop badge effect reading another list. Detail polling resets review fields on every read.
- Shared Query infrastructure, auth/transport, router, local transfers and durable Job task-center are outside this slice.

## Profiles and statistics ownership checkpoint

Profiles now own two shared Query catalogs in `lib/queries/profiles.ts`. The card reads those catalogs directly; component state contains only add forms, sparse per-row drafts with captured bases, validation, confirmation and pending feedback. Background reads, confirmed creates and Spoolman synchronization leave other row drafts intact. Server DTOs publish after canceling obsolete reads, followed by one catalog revalidation for alphabetical order and computed usage counts. The backend PATCH projection currently returns usage_count=0 while the list computes actual usage, so the list read remains necessary. Metadata inputs and deletion are blocked for a pending row. Every command carries the gesture's session incarnation through preparation, request dispatch and publication; retired callbacks cannot publish. The parent AuthProvider retires private feature-local state on an incarnation change.

`lib/queries/statistics.ts` owns period-complete Query keys and forwards cancellation into the typed endpoint. The page retains its browser-local chart/widget preferences and exposes explicit read retry. Completed print statistics use resolved historical cost/weight; later profile price changes do not change those totals, so profile writes do not invalidate historical statistics.

The three existing profile/statistics hooks delegate to these option factories while preserving QueryApiProvider collaborators. This is temporary migration compatibility, with caller cutover/facade removal assigned to M10. The transport's profile catalog invalidations and sync-to-profile invalidation were removed once the sole profile writer moved to the feature owner. Unmigrated Spoolman settings/status/spools retain their existing compatibility invalidation. No generic repository or forwarding-only new hook was introduced.

Profiles have no backend edit_version or conditional-write contract. Captured draft bases prevent local refresh clobbering; they do not establish protection from competing external profile edits or prove lost-acknowledgement recovery. Those limits are retained without inventing protocol or automatic mutation retries.
