# Slack custom emoji

Slack is one output target for Emoji Forge. Use the general workflow for any character or target. Other platforms, such as Discord or Telegram stickers, can have their own export reference.

- Use a **128×128 px square** master for review and delivery. This is this skill's working recommendation. Slack recommends square artwork with transparent backgrounds under 128 KB, accepts GIF, PNG and JPG, and documents a maximum of 50 GIF frames. Use a conservative budget of 128,000 bytes and no more than 50 decoded frames. [Slack custom emoji help](https://slack.com/help/articles/206870177-Add-custom-emoji-and-aliases-to-your-workspace)
- GIF holds are frame delays and count as one encoded frame when identical exposures merge. Use `--loop 0` for indefinite repeats. Slack lets viewers disable automatic animation. Consider testing the first frame on its own and previewing the reaction at 22–32 px. [Slack animation preferences](https://slack.com/help/articles/228023907-Manage-animated-images-and-emoji)
- Use short lowercase names with digits, hyphens or underscores where needed, such as `coffee` or `big-win`. Use the same filename stem. Skip names already taken. [Slack custom emoji help](https://slack.com/help/articles/206870177-Add-custom-emoji-and-aliases-to-your-workspace)
- For both Slack themes, use a contrasting outline around the silhouette. GIF supports one transparent palette index. For smooth glow on dark mode, test a dark matte and compare the visible tile on light mode. PNG can retain soft alpha for static emoji.
- A human uploads the individual files. **Agents must not upload custom emoji on the user's behalf.** In the workspace customization interface use **Customize workspace → Emoji → Add custom emoji** where available. Slack's current desktop help documents **emoji picker → Add Emoji → Upload Image → Save**. Owners may restrict permission. [Slack upload instructions](https://slack.com/help/articles/206870177-Add-custom-emoji-and-aliases-to-your-workspace)
